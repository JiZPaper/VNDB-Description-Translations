# 项目长期约定

- 本仓库保存VNDB视觉小说与角色简介的人工多语言译文，供PaperVN及其他使用者使用。
- 简体中文翻译放在`zh-Hans`，必须与`en`保持相同相对路径；复制全部字段，只把`language`改为`zh-Hans`并将`translation`替换为完整人工译文。
- `source`、`source_sha256`及其他元数据必须与对应英文文件一致；原文更新导致哈希不同后需重新审校。
- `[url]`、`[spoiler]`等VNDB标记需要完整保留、正确配对；保留原文分段。
- 简中翻译优先自然、准确、使用作品通行译名；避免在中文/日文与西文或数字之间手动添加空格。
- 翻译必须严格按照VNDB数字ID升序推进，不按长度、题材或标记挑选和跳过；遇到不确定的人名、地名、组织或作品术语时，先联网查证通行译名。
- 每轮以实际创建、通过校验并最终保留的1000份简中JSON为一个对外批次；内部仍按约50个数字ID的可恢复区间逐段翻译与校验，并在每个区间完成后即时更新拒绝清单。分类、拒绝项和缺失英文源不计入这1000份译文。
- 中文标点必须规范并尽量保持原文点数语义：英文`...`转换为单个中文省略号`…`，不得擅自扩成`……`；原文本身为六点或中文完整省略号时才使用`……`。避免不规范半角括号；中文/日文与西文或数字之间不手动添加空格。
- 成人角色相关内容可以正常翻译、复核和润色；涉及未成年人性化或性剥削的条目只做结构检查和分类，不进行正文翻译或润色，也不计入人工审校完成。
- 每批完成内容分类与可处理译文写入后，必须把该批所有因内容边界未创建简中JSON的现有英文条目去重追加到`zh-Hans/GPT-5.6 Sol拒绝翻译条目.txt`，同步更新条目总数；不得把缺失英文源文件计入清单。
